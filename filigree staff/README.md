# Modular Filigree Staff — Master 25-Piece Design Catalog

This modular library contains **25 distinct interchangeable components** engineered for 3D printing cosplay staffs via Tripo AI. Every component terminates with standardized, flush **cylindrical connection collars**, allowing you to stack any combination of head, middle sections, and finale, and easily add internal core rods ($1/2''$ PVC, $12\text{ mm}$ carbon tube) or slicer dowels in Bambu Studio / OrcaSlicer.

## 4. 3D Assembly & Slicer Tips
- **Internal Core Rod (Strongest)**: In Bambu Studio / OrcaSlicer, add a **Negative Part $\rightarrow$ Cylinder** ($12\text{ mm}$ or $16\text{ mm}$) running through the center of every piece. Slide the printed sections over a solid aluminum or carbon fiber core tube for maximum bending strength.
- **Slicer Connectors**: Use the slicer's built-in **Cut tool $\rightarrow$ Add Connectors (Dowel)** with $0.15\text{ mm}$ clearance on the flat cylindrical faces.
